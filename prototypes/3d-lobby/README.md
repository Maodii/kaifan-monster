# 开饭小怪：五个生活空间

方向确认用网页原型。现有原生主题保留为「简洁模式」；本目录提供候选 3D 模式和隔离的简洁模式演示，没有替换双端正式应用。

## 运行

在项目根目录执行 `node prototypes/3d-lobby/server.mjs`，访问 http://127.0.0.1:4317 。首次安装此原型依赖可执行 `npm ci --prefix prototypes/3d-lobby`。所有 Three.js 模块、模型、字体与菜谱封面均从本机读取。

## 场景与交互

| 导航 | 原创场景 | 可体验的面板 |
| --- | --- | --- |
| 今日记餐 | 三餐手账、翻页日历、花费小票、当餐食物 | 日期切换，三餐记录，花费、照片、评分、热量 |
| 菜谱厨房 | 灶台、炖锅、厨刀案板、水槽、分步食谱 | 450 道现有菜谱，组合分类/搜索，实际做法，红心收藏，食材加入采购 |
| 我的冰箱 | 有内胆、铰链、门架、冷藏层板和蛋托的可开合冰箱 | 冷藏/冷冻/常温示例分区，食材找菜，示例消耗记录，采购清单 |
| 餐桌广场 | 交流亭、曲面条纹篷布、餐食照片墙、共享长桌 | 示例帖子，本页图文发布，点赞 |
| 我的小怪 | 连续网格小怪、示例主体名牌、角色围裙、徽章与收藏柜 | 本地昵称、口味、用餐方式，收藏，显示模式 |

底部导航切换真实模型；点击场景物件或空间主按钮打开面板。拖动旋转，滚轮/双指缩放，或使用「− / ＋ / ↺」。近景是实际几何，不是放大一张图。厨房保留随机抽菜、时间约束及食材采购入口。切换场景可中断；只保留当前场景的 GPU 几何/材质。

## 美术源文件

- `art-source/lobby3d/detailed-spaces.blend`：五个精修场景，含命名部件。
- `scripts/lobby3d/build_detail.py` 与 `scripts/lobby3d/detail/`：逐件编写的建模脚本。
- `docs/lobby3d-detail.md`：55 个部件及各自细节清单。
- `prototypes/3d-lobby/assets/*.glb`：实时渲染模型。

统一材质方向为奶油墙面、木质底座、多彩陶土和手作边角，配合实时光照、阴影、细微纸纹凹凸。模型使用 PBR 材质。近景有米粒、杯把、筷子、罐盖、番茄叶、藤架灯串、手账笔迹等独立几何。场景是原创程序建模，不是外部 AI 3D 服务生成。是否继续深化此风格由用户确认。

## 验证与边界

`node scripts/lobby3d/test-demo.cjs`：基础交互验证。

`node scripts/lobby3d/test-detail.cjs`：逐件检视、隔离完整性、五场景、面板、跨场景 GPU 分配、320/390/768px 排版验证。真实浏览器截图保存在 `work/screenshots/`；报告在 `work/reports/lobby3d-*.json`。

3D 渲染限制 DPR≤1.5、约 30fps；进入简洁模式/页面不可见时停止渲染循环。WebGL 不可用时提供简洁模式入口。切换按需加载一个 GLB，旧场景几何/材质释放。此限制只代表原型策略，不等于已完成低端真机帧率、功耗或原生端性能验收。

记录使用独立 localStorage `kaifan-lobby-art-demo:v1`，不会写入原生数据库或生产社区。社区、库存和消耗示例显式标识，示例主体档案不代表真实账号登录。照片缩至最长边720px，并限制文件大小和本页记录数量。没有把正式双端所有业务搬入网页；本轮交付用于确认场景、UI 和操作方向，原生 3D 接入在方向确认后实施。
