# 3D 大厅部件精修

本轮替换第一版基础体块。五个导航分别以记餐手账、烹饪工作台、真实冰箱、社区交流广场和示例主体角色为视觉主体。下列是可在网页「部件检视」中选择、放大和隔离的独立部件；结构验证不等同于用户已认可美术质量。

## 查看方式

- 运行中的网页：http://127.0.0.1:4317
- 每个场景右上角「部件检视」可选部件；「单独查看」隐藏其它部件；↺恢复整景。
- 冰箱可开合门；滚轮/双指及＋/－调节距离。
- 部件边界在材质合批后保留，可逐件编辑。

## 源文件与验证

- 可编辑 Blender 源文件：`art-source/lobby3d/detailed-spaces.blend`，包含五个独立 scene。
- 建模入口：`scripts/lobby3d/build_detail.py`；每个场景分文件于 `scripts/lobby3d/detail/`，共同工具只负责截面旋转、曲面、样条管道等结构。
- 实时 GLB：`prototypes/3d-lobby/assets/`，当前仍是网页候选模式，未改原生正式包。
- PBR 区分搪瓷、金属、玻璃、木质、纸张、织物；真实环境反射、接触阴影与局部轮廓细节。没有把 Blender 专用材质当作可直接移植的结果。
- 每个部件有原始结构与独立名称；连续网格、内外壁、管道截面、布料曲面和纸页替代旧版的球体拼装主体。
- 浏览器检查：`node scripts/lobby3d/test-detail.cjs`；业务演示回归：`node scripts/lobby3d/test-demo.cjs`。报告在 `work/reports/lobby3d-detail-demo.json` 与 `lobby3d-demo.json`。
- 真实截图在 `work/screenshots/lobby3d-detail-*.png`。按用户偏好覆盖同名本轮确认截图，未复制整项目。

## 性能与交付边界

部件几何增多后，尚需真机验证帧率、峰值显存、耗电与原生渲染管线。本轮先验证网页实际模型、语义、部件完整显示、资源释放与窄屏布局；约30fps是调度上限，不代表真机已达到30fps。简洁模式继续可用。

## 角色乱毛修订

以桌面品牌 Logo 为身份参考，生图得到 Q 萌与乱毛设计参考，再分别制作可实时旋转的模型。参考图位于 `work/generated-art/lobby3d/cute-monster-fluffy.png`，提示词位于 `art-source/lobby3d/fluffy-monster-edit-prompt.txt`。参考图不是 WebGL 截图，实时模型仍受实时毛发渲染成本限制。毛发使用错落弯垂的片状毛束和切线方向细绒，避免径向锥体尖刺；保留短耳、椭圆眼、微笑、抱碗。
