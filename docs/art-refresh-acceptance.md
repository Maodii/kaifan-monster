# 0.4.2 食物手账视觉迭代

本轮完成实际页面调整，使用原创品牌插画、现有逐菜封面和生成图标；文字、点击区域与表单仍由客户端渲染，未使用整张生成UI图代替界面。

## 参考与取舍

2026-11-06 使用无窗口浏览器查看 [Cookpad](https://cookpad.com/)、[下厨房](https://www.xiachufang.com/)、[豆果](https://www.douguo.com/) 公开网页。参考确认截图登记在 work/artifacts.json，页面标题/栏目记录在 work/reports/art-refresh-research.json。Cookpad的主次图片与食材入口、下厨房的分类与作品内容、豆果的菜谱/笔记栏目提供信息组织参考；本项目保留原创蜡笔品牌风格，不复刻其图片或商标。Kitchen Stories与BBC Good Food请求失败，未作为已目检参考。

## 已落地

- 首页：压缩品牌抬头，趣味标语与透明蜡笔餐桌插画并排；日历保留切换；常买/同步和重复快捷记餐后移，三餐优先展示。
- 三餐：麦黄、鼠尾草绿、淡紫纸条与左侧色线，栏目图标独立；点击区不随装饰倾斜。
- 菜谱：保留独立窄搜索，排序横向收纳，分页降级为中性色；放大菜品图片，交替纸色和多色蜡笔承托；时间短标签单行，名称与做法优先。
- 社区：靛蓝标题、暖纸卡片与照片优先层级；搜索、分区、筛选与分享逻辑保留。
- 食材：标题前置，购买与消耗历史保留显眼入口，采购使用对应插画；简化说明文字。
- 记餐：费用汇总改为麦色纸签，保留示例主体热量、用餐方式与历史记录。
- 设置：七项紧凑插画行，黄/绿/紫三色交替，版本与生活工具后置，图标仅轻微装饰倾斜。
- 全局：标题/正文层级、异形纸角、细线和低强度阴影；不新增持续动画、后台计时或大图循环，已有减少动态效果设置继续生效。

## 原创插画

通过 api-image 技能的配置服务生成，模型 gpt-image-2.5-flare，以现有品牌小怪为身份参考。必要原图和完整提示词位于 art-source/table-collage/original.png、prompt.txt。正式透明图 client/entry/src/main/resources/base/media/table_collage.png 为1024×498；通过边缘连通背景抠除保留食物、小怪和蜡笔拼贴边缘。原图没有作为界面背景硬铺满。
