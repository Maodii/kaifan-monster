# 手势与转场

本轮使用 ArkUI 原生手势与属性动画，无外部动画运行时，也不额外下载素材。

## 操作

- 主页面按底栏顺序「今日 → 菜谱 → 记餐 → 食材 → 我的」左右滑动切换；首尾不循环。
- 各主页面保留各自的滚动位置；再次点击当前底栏项平滑回顶部。
- 详情从应用内容左侧约 28vp 范围向右滑返回。屏幕最外沿仍归系统手势，模拟器实测最外侧会打开系统侧边栏，应用不覆盖系统行为。
- 横向位移需达到64vp且明显大于纵向位移；短滑取消时回弹。忙碌、抽取过程中不切页。
- 周历区域左右滑切上一周/下一周；展开月历后滑动日期区切月。日历自己的手势优先于主页面切换。
- 烹饪页左右滑切步骤，边界不越界；从左侧返回详情时不切步骤。步骤进度仍自动保存。
- 双击菜谱顶部菜名平滑回到正文开头。爱心与返回按钮保持独立点击操作。
- 菜谱搜索框输入后显示系统清空按钮。
- 未保存表单返回沿用原有确认流程；滑动不会提交、扣库存或保存记录。

## 动画表现

1. 主页面根据方向横向进入，同时轻微上浮、淡入。
2. 返回采用反方向进入。
3. 左侧返回拖动时内容轻跟手，距离限制72vp。
4. 不满足返回条件时180ms回弹。
5. 周历切换平移与透明度过渡。
6. 月历切换平移与透明度过渡，展开带淡入及位移。
7. 日期选中底纹平滑变化并固定居中。
8. 烹饪步骤沿滑动方向切换并淡入。
9. 点选芯片按压缩小、松开恢复。
10. 底栏按压缩小，选中项回弹放大。
11. 菜谱列表增减以轻位移、透明度过渡呈现。
12. 重复点击底栏与双击菜名的回顶部有滚动过渡。

所有新增位移、缩放与过渡遵循“减少动画”，手势导航在减少动画时仍可使用。没有人为增加启动等待或保存延迟。静态截图及流程测试不等于帧率基准。

## 验证

原生手势脚本 `scripts/native-gesture-motion.py` 检查主页面双向滑动、日历切周、菜谱左侧返回、烹饪步骤双向切换和未保存记餐确认。`native-gesture-navigation.py` 检查横向滚动冲突、短滑保护、切页位置恢复、月份滑动及快速回顶；`native-gesture-reduced-motion.py` 验证减少动画偏好持久化及手势可用，测试后恢复原偏好。补充检查独立记录在原生验证报告；最终包内资源及报告见 `work/reports/gesture-motion-release.json`。
