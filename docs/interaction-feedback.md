# 双端点击反馈与触摸热区（2026-11-18）

本次修改 Android WebView 与原生 HarmonyOS 常用交互。本次交互优化已纳入 0.9.30（48）的双端正式包；包内容、签名与哈希校验见 `work/reports/interaction-dual-release.json`。旧 debug/unsigned 导出不属于本次正式交付。

- Android 按钮、语义按钮和 summary 按下时增加亮度变化及内描边，键盘焦点使用清晰的外边框。系统减少动态效果时仍保留颜色反馈。
- AI 工具、输入辅助操作、回复工具栏、短信帮助及记餐筛选等按钮补足 44px 实际触摸尺寸；不通过重叠透明区域扩大触摸范围。一周日期在窄屏保持 44px 最小宽度，允许横向滑动。
- Android 指定工具组统一 8px 间距，弹窗底部操作保持 12px；常规触摸高度 44px、主要操作 48px。原有页面留白和字体沿用现有设计。
- Android 显式点击或表单提交超过 300ms 显示“正在处理，请稍候”，结束后清理提示和辅助状态。短操作与后台自动保存不闪提示，原有重复提交保护保留。打开确认弹窗时隐藏处理提示。
- HarmonyOS 扩大 AI 输入、上下文、回复工具、菜数和提醒天数等小按钮，补充按压透明度；底部导航与筛选芯片增加按压背景色；共享 run 流程超过 300ms 显示非阻塞的加载提示。
- 修复 Android 无对话内容时误显示“回到最新”，避免覆盖推荐问题。

验证入口：`node scripts/android/build-web.cjs`、`node scripts/android/test-interaction-feedback.cjs`。详细测量在 `work/reports/interaction-feedback-ui.json`；覆盖 7 个常用页面 × 320/390/768 宽度、44px 按钮尺寸、边缘点击、按压与释放、统一间距、慢操作去重和提示清理、快操作及后台自动保存静默。另跑短信、弹窗、隐私流程回归及鸿蒙 assembleHap 编译。

浏览器验证使用 SQLite 桥接适配器，不发送真实短信或付费 AI 请求；不等同于真机验证。上架前应在 Android 与鸿蒙真机补测键盘弹出、大字体、横屏、屏幕阅读器及滑动取消手势。
