# 开饭小怪 0.9.23 / 41

同一把百炼密钥可以联网，无需另购搜索服务。此前 Chat Completions 调用未提供可核验来源；现在勾选联网时使用 Responses API 的内置 `web_search`，并用 `tool_choice=required` 要求实际检索。官方说明：https://help.aliyun.com/zh/model-studio/web-search 。

## 使用

- 菜谱搜索页点“让AI联网找新做法”，输入菜名或食材，确认本次发送后提问。
- AI 的“更多帮手”可选“AI做新菜”“估营养花费”；新菜可调整人数、时间、预算、地区和忌口，联网单独选择。
- 食材分类页和库存 AI 入口可设计库外新菜。库存名称只在勾选时附带，排除已归档、过期及家庭共享记录，最多20项。
- 新菜可展开用料与步骤，核对后进入私房菜编辑器；估算可进入新的记餐编辑器。点击编辑器保存才写入数据，模型不会直接扣库存或覆盖现有记餐。
- 真实搜索显示工具返回的参考来源，未搜索显示“未联网”。生成菜谱按每人给营养范围、整道给费用范围；估算记餐按本人食用份量。保存的代表值取范围中值，原始范围和假设保存在备注及结构字段中，费用标为估算。

## 防护与验证

来源仅从实际搜索工具结果提取，忽略模型自行生成的链接、身份及记录ID；仅保留公网 HTTPS 链接，不代替用户抓取网页。网页内容按不可信资料处理。鉴权、账号隔离、每日额度、取消及重复请求保护继续生效。禁用不相关业务，未匹配安全规则不代表能保证模型永不出错。

联网有独立30秒网关上限，业务请求与异步任务35秒；普通请求原有上限不变。检索没有可核验来源、超时、结构错误或超出约束会回退，不冒充联网成功。

本次同时替换了 Android 默认确认框：纸张底纹、品牌角色、明确采购动作、等宽按钮、进入退出动效，保留取消和一次性回调语义。
