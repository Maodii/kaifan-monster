# 小怪聊天界面 0.9.1

使用用户截图中同款的既有高清透明图 `client/entry/src/main/resources/base/media/brand_monster.png`，保留紫色乱毛、米黄色眼睛、饭碗与蜡笔纹理；没有重新生成另一只角色，也没有把截图放大成模糊素材。

## 交互与视觉

- 首页小怪邀请入口可点击进入聊天；呼吸摇摆、轻浮阴影与闪光点增强角色感。
- 对话首屏只有角色、两条快捷提问、输入框与发送按钮。暖纸底色配灰紫色气泡和蜂蜜色点缀，减少大块规则卡片。
- 顶栏返回和新对话使用图标；等待期间新对话图标变成取消等待。
- 固定底部输入区，长消息在对话区滚动；用户与 AI 消息区分。发送后清空输入框，错误时恢复原问题以便重试。
- “更多帮手”按需打开做法、主菜草案、库存和记餐工具；条件、库存及上下文选项收纳其中。发送时收起，保留计划确认与记餐编辑保护。
- 同意发送本次对话后，普通追问默认附带上一轮问答。可以关闭上下文，点新对话或切换账号即清空。仅保存在内存，展示与请求历史均有上限。
- 库存仍单独授权；记餐任务仍不携带库存或历史。社区继续隐藏。
- 使用系统布局与变换动画，不新增动画插件、不逐帧加载多张大图。支持减少动态效果，后台暂停角色动态。
