# 下一轮10项实施

用户于2026-11-06授权继续全部制作。主对话负责鸿蒙、共享业务与后端，Android专门对话负责Android。继续后台执行，不启动高内存模拟器、不保留全量检查点。

1. 双端设备验收：检测实际设备，建立明确的安装/离线/重启/媒体/通知流程；无设备如实待验收。
2. 启动与内存：有界菜谱分页、图片解码、定时器释放、去重；设备基线工具。
3. 工作区逐项三方合并：计划、收藏夹、筛选、成员、偏好，包括删除；并发修改需选择。
4. 首页四餐快速记餐与历史复用：历史日期生效、未来转计划、保留草稿确认。
5. 菜谱质量：12类常见操作建议、质量问题识别、用户纠错→管理端处理，原始步骤保留。
6. 整餐组合：用户选择双灶估时，按现有时间线计算；荤素组合条件不自动放宽。
7. 推荐反馈：场景隔离、午夜过期的临时跳过，不影响长期学习；长期忌口入口。
8. 采购闭环：库存/上次日期/单价参考；部分买到分批入库、余量继续待购，冲突拒绝。
9. 热量可信度：来源、参考整份量、实际吃下比例、实际摄入校验与旧记录兼容。
10. 设计与无障碍：居中无勾筛选、辅助标签、触点、焦点、折叠和减少动画；逐页设备视觉待验收。

共享源稳定后再由Android生成；不声称共享业务代表像素完全一致。主状态仅work/task-state.json，Android独立work/android-status.json。最终单份HAP/APK覆盖交付，源码/测试/包内容对应。
