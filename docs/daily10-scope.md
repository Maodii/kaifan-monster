# 日常使用强化 0.4.0

本轮为用户最新授权的10项，独立于0.3.0的next10。

1. 连接设备安装、离线、重启、照片、通知、内存验收；无设备保留待验收，不启动高占用模拟器。
2. 鸿蒙与安卓逐页行为与视觉对齐，不能以共享源码代替设备验收。
3. 大字烹饪步骤、当前用料、多计时与续做。
4. 临期优先、不重复、保留已安排项的周计划草案；采购与预算按当前计划重算。
5. 剩菜容器、冷藏/冷冻、手动日期、分次食用或丢弃，避免重复计费和扣库存。
6. 试做结果、实际用时、真实用户自报与演示分离的证据统计。
7. 可选密码加密备份、导入预览、30天/最多30条本机回收站；不自动备份项目。
8. 常去店铺、常点组合、再记一餐与示例主体支出。
9. 七天营养记录覆盖与来源，未知不计零。
10. 社区按菜谱、地区、试做结果筛选，收藏经验与演示标识。

后台执行，使用单份任务状态，不复制整项目。双端版本0.4.0/code6，真机证据未通过的项目保持待验收。
