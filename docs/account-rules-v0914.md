# 0.9.14 账号规则与界面精简

- 注册使用自定义账号，无需邮箱验证。新账号可用 2–32 位中文、英文字母、数字、下划线和短横线，去除首尾空白、英文字母不区分大小写。同名账号不能重复注册。
- 注册、修改密码、保留的旧邮箱重置 API 统一要求：6–128 位，至少包含一个英文字母和一个数字；可以包含额外符号。例如 `abc123`、`A12345`。
- 登录不重新强制新密码规则，保留旧邮箱账号和已有密码的兼容性。改密码仍需验证当前密码，并使原有登录设备会话失效。
- 鸿蒙与 Android 均移除高级连接、手动服务地址、连接检测、恢复默认服务操作；继续自动使用已配置的服务。不会因移除界面而重置账号、迁移示例主体数据或擅自替换原有自建服务地址。
- 移除邮箱验证及邮件找回入口，账号安全保留注销功能，修改密码仍在账号页。旧恢复路由仅展示账号帮助，不提供不安全的免验证重置。
- 登录与注册分别保留服务端每 IP 每分钟 10 次、5 次限流。密码继续以 Argon2 哈希保存，不保存明文。

兼容性：HTTP 字段 `email` 与 PostgreSQL `users.email` 暂保留原名称，现表示登录账号标识，可保存自定义账号；无需改表或搬迁已有用户。客服只读账号视图中同名列也可能显示自定义账号。

验证：后端规则 5 组、浏览器账号界面 5 组（含窄屏、无连接/邮箱验证入口、旧密码登录兼容），另有真实公网注册/登录/重复账号/修改密码/会话失效 5 组。公网测试账号已注销，没有上传示例主体业务记录。两端构建完成；鸿蒙模拟器覆盖安装保留数据。Android 真机行为未在本轮验收。
