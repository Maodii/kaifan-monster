# 后续开发与验证方向

本轮 20 项已接入，见 [逐项验收](optimization-20-acceptance.md)。离线目录增量更新、计划采购闭环、家庭认领、快捷记餐、收藏夹、社区分页、编辑质量队列及历史恢复均已实现。

| 优先级 | 后续方向 | 具体目标 |
| --- | --- | --- |
| P0 | 原生与性能验收 | 主机压力安全后走查最终 HAP，记录冷启动、长滑动、帧率及应用/模拟器各自内存 |
| P0 | 真机专项 | 签名安装、相机相册、亮屏与后台提醒、桌面卡片实际验证 |
| P1 | 内容持续核实 | 管理端质量队列补齐来源、可食部、生熟重、未知用量和步骤状态 |
| P1 | 推荐评估 | 用真实行为评估重复率、利用库存、预算和地区适配；演示行为单独统计 |
| P1 | 账号与部署 | 按需要接入真实邮件、远程 HTTPS、鸿蒙云；补多管理员角色、二次验证及双人审批 |
| P2 | 协作深化 | 家庭成员食量/忌口合并、实时推送、共享计划冲突提示 |
| P2 | 长期运营 | 社区反垃圾、举报时效、精选运营；大目录数据库检索索引及容量压测 |

本地自动测试及编译通过不代表已完成上述硬件与线上环境验收。
