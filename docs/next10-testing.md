# 0.3.0 测试入口

Android最终测试包为outputs/kaifan-monster-android-debug.apk，安装后在“我的”确认0.3.0(5)，不要继续测旧0.2.0。鸿蒙outputs/shiku-mvp-unsigned.hap为未签名编译产物，需通过DevEco的设备签名配置后安装；本轮没有代替用户完成真机签名。

本地管理端：http://127.0.0.1:3001/admin/，既有本地本地私密账号配置。手机访问API须使用开发Mac可达地址，手机上的127.0.0.1不是Mac；以设置里的连接测试为准。

## 真机验收路径（待执行）

1. 在独立测试账号中注册/登录，新建食材与记餐；退出再登录，确认账号空间隔离。
2. 飞行模式下重启应用，查看菜谱、库存、计划；录入一项后恢复网络，同步一次，再同步不应重复。
3. 建一个2kg采购项，先买500g，确认库存增加500g、待购剩1.5kg；再买齐只完成一次。
4. 两个设备分别改不同计划和同名收藏夹，进入同步对照；独立变化自动保留，同项冲突须选择。测试删除项不复活。
5. 录800kcal整份、吃25%、来源包装标签；保存后应是200kcal，编辑仍显示800与25%。
6. 今天跳过某菜，做饭场景不再推荐，外食场景保持独立；长期忌口需确认，可从设置移除。
7. 在家做抽两菜一汤，选双灶和荤素；核对预算/人数、备料与时间线，确认不自动扣库存。
8. 拍照/相册取消和保存、照片同步重试、通知、烹饪亮屏、桌面卡片、系统返回逐项测试。
9. 字号200%、深色、横竖屏、减少动画/屏幕阅读器，检查筛选居中、固定按钮可见、弹层焦点和日期切换。
10. 记录应用进程内存与冷启动、滚动、看20张图片、往返页面后的变化；明确设备型号和系统。模拟器本身占用不能证明应用泄漏。

## 后台验证命令

在工程根运行python3 scripts/test-next10.py；运行python3 scripts/verify-next10-ui-source.py检查实际鸿蒙页面注册；构建日志位于work/reports/next10-build.log。设备性能工具scripts/harmony-baseline.py和scripts/android/measure-device.py默认不创建模拟器，不将无设备报告当作通过。
