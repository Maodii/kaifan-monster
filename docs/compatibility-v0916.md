# 0.9.16（34）兼容检查

本轮已完成代码检查、双端构建、安装包校验和鸿蒙模拟器无业务写入走查。测试通过表示以下范围内未再复现问题，不代表所有机型均已认证。

## 已修复

| 问题 | 触发与影响 | 处理与验证 |
| --- | --- | --- |
| 鸿蒙网络状态权限遗漏 | 开启仅 Wi-Fi 自动同步后，获取网络类型可能报权限错误 | 根据本机 SDK 的权限声明补齐 GET_NETWORK_INFO；构建、HAP 内容和安装后的 bundle 声明检查通过 |
| WebView 90 缺少 Array.at | AI 发送、返回导航、键盘焦点循环可能抛异常，发送状态无法正常继续 | 改用数组下标；在测试页面删除 Array.prototype.at 后，56 组 AI 和 23 组伙伴流程通过；此方法不等同于完整旧 WebView 实机测试 |
| 系统照片/文件选择返回异常 | RESULT_OK 但没有 Intent/URI，或图片解码失败 | 增加空值与解码结果保护，仅处理本应用的请求码；代码检查和 Java 编译通过，异常系统回传尚未在安卓实机复现验收 |
| 相机/导出异步参数串用 | 后台处理尚未结束时再次操作，可能读取被覆盖的 cameraName/exportText | 在回调开始时快照参数，后台只使用本次参数；代码检查和编译通过，真实并发系统选择仍待设备验证 |
| 两套页面动画叠加 | AI 模块对整个主页面位移，影响固定操作栏与页面转场 | 移除额外的整页 transform，保留统一转场控制；动画回归通过 |
| 菜图转场残留 | 过渡中返回、切后台、开启减少动画，或 animate 抛异常 | 统一取消动画、移除浮图并恢复目标图片；新增背景切换、减少动画、API 失败三个回归用例通过 |

响应式测试另修复一处测试误报：将步骤区的内联 nav 误认为底部导航，现改为明确检查 #nav 和 #page-header；没有放宽原有间距、溢出、文字和图片比例断言。

## 验证结果

- 504 个页面/尺寸/字体组合：320–1024px 宽度，常规与 1.3 倍根字体、横竖屏、长标题及图片比例检查通过。
- 56 组 AI、23 组伙伴交互、19 项动画、5 组账号规则、8 组输入/返回导航检查通过。
- 10 套本地单元/回归套件通过，覆盖地址迁移、令牌刷新、备份加密、库存事务、推荐和生活工具。
- 14 组共享数据库/业务测试通过，包括真实 HTTPS 注册与同步、私有账号隔离、库存事务回滚及冲突处理；测试只使用自己的临时账号。
- 后端 TypeScript 类型检查通过。公网健康接口 200，未登录读取账号及调用 AI 均为 401；没有进行付费模型推理压测。
- HAP、安卓 debug/release 包的版本与内容一致，安卓 v2/v3 签名验证通过，release 不可调试，均无 3D 场景资源。
- 鸿蒙模拟器覆盖安装成功，新增权限声明与五个主页面检查通过，返回首页，未操作用户业务数据。

## 仍需真实设备验收

安卓最低 Android 8（API 26），系统 WebView 需 90 或以上；当前没有连接安卓设备。厂商相机、相册、通知/闹钟、真实 textZoom 与老 WebView 的完整渲染仍待实机验证。鸿蒙工程兼容版本为 HarmonyOS 6.1.1（API 24）及以上，当前仅有模拟器证据，HAP 仍需正式签名后分发至真机。
