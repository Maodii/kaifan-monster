# 0.4.4 紧凑搜索长条

按用户截图将菜谱、社区搜索入口收为长条：保留居中窄宽，移除上下20vp内边距，最小点击高度44vp，放大镜20vp，提示15vp，收小圆角。搜索输入页及业务行为保持原有逻辑。入口不加固定最大高度，字体放大时允许必要的内容高度。

鸿蒙编译/源路由检查及既有模拟器高度实测分别见search-strip-build.log、search-strip-ui-source.json、search-strip-native.json；上一版入口原生277px，本版以当前报告测量值为准。Android仅对两个入口及独立搜索跳转做针对响应式验证，未将旧版全量504场景声称为本轮新执行。最终双包以search-strip-dual-release.json为准；真机验收和跨端全像素一致不在本轮结论内。
