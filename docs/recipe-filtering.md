# 菜谱组合筛选

餐次独立于类别；同一菜可属于多个餐次。支持早餐、午餐、晚餐、加餐。源数据未提供餐次时，采用可解释的保守规则：早餐类别推荐早餐，粥类可搭配早午晚餐，甜点/饮品建议加餐，常见早餐形式的菜名可搭配早午晚餐，其余正餐菜谱建议午晚餐。它是搭配建议，不是营养判断。后续 `mealOccasions` 显式标签优先，不修改来源类别。

筛选同一维度多选按“或”，不同维度按“且”；指定多个现有食材时，菜谱需要全部包含。地区与口味选项取自实际目录。目标只匹配已有 dietTags，不根据名称或缺失的卡路里推定减脂/高蛋白。制作时间包含现有目录记录的备料估时，外食场景明确不是配送/到店时长。

“用上现有食材”需要至少一种未过期、未归档且数量大于零的主料，单位可换算。“主料够用”必须所有非可选原料有已知用量且有效库存足够；重复同一原料需求先合并，防止重复使用同一份库存。食材别名和单位换算复用推荐引擎。

打开筛选复制一份草稿，调整不会改变已显示结果；应用提交草稿，取消放弃草稿。重置只重置草稿；外层清空立即清空全部筛选。类别快捷入口可多选并立即应用。摘要始终对应已应用条件，饮食偏好/忌口不随清空条件被删除。
