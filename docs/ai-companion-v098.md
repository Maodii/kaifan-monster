# 开饭小怪 0.9.8：动作与过渡细化

沿用蜡笔小怪及现有正式素材，重点修正突跳、换图感和动作触发的一致性。未加入动画框架或持续每帧 JavaScript 模拟。

## 实际改动

- Android 姿态切换保留旧图层与新图层交叠 220ms；新动作覆盖旧动作时先清理旧动画，退后台及减少动态效果时结束混合，保持完整静态帧。
- 拖动按水平位移产生至多 9° 的轻微倾斜，增加轻微放大与阴影变化；释放后平滑吸边并给予 360ms 的轻落位反馈。鸿蒙同步使用共享倾斜边界和原生属性动画。
- 修正对话下拉关闭先回零再退场的突跳。Android 从当前拉动距离继续淡出，鸿蒙不再在退出前重置位移；短拖、横拖和取消仍回位。
- 延长待机动作停留，降低自动大幅动作出现频率，保留低幅呼吸与眨眼；主动选择动作仍立即反馈。
- 鸿蒙补齐伸腰动作，为重复选择同一动作增加独立触发计数；动作结束后回到有限待机序列。减少动态效果时展示用户所选动作的完整静态帧。
- Android 支持小怪获得焦点后按上下方向键打开动作菜单；选择动作、Escape 关闭均恢复焦点，Tab 移出菜单时收起，不主动打开聊天。
- 拉手按下与动作按钮增加克制的按压反馈；后台清除落位定时器和正在进行的拉手拖动。

## 验证与边界

`companion-ui.json` 包含 20 组宿主交互检查，增加换姿态双图层及后台清理、纯键盘动作操作，并实际测量下拉关闭开始时面板位置，防止回零突跳。`companion-core.json` 的 6 组共享测试包含倾斜、位移及异常数值边界。原有 49 组 AI、14 组 SQLite/真实 HTTP 业务、8 组导航输入回归继续核验。

`companion-preview.gif` 展示实际宿主 UI 的动作菜单、跟手拖动、姿态过渡与下拉退场；回答使用测试替身。`companion-performance.json` 记录 12 次开关、显式 GC 前后 JS/DOM 指标及后台暂停；不作为手机 GPU/原生内存结论。

双包为 0.9.8 / code26。鸿蒙后台编译通过，原生动作观感、软键盘和触摸手感需要真机验收；没有启动模拟器、IDE或前台预览。HAP 仍需开发者签名，暂无公网 HTTPS 时沿用已有转发测试。
