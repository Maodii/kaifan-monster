# 小怪助手 0.9.0 测试版

鸿蒙与安卓新增四种工作流，使用同一个鉴权业务接口 `/api/v1/ai/assist`。服务器运行 FastAPI 推理网关，调用阿里云 qwen3.8-flash；没有在这台服务器加载模型权重。社区继续隐藏。

## 怎么用

进入“小怪助手”，选择功能并勾选发送同意。默认不附带库存或上一轮对话。

- **问做法**：选择快捷问题或输入问题。可单独勾选带上上一轮问答；只在当前页面内存保存，切换账号或清空后移除。
- **一周灵感**：选择 3/7 天、起始日期、人数、单道菜时长、整菜预算、地区及不吃的食材。生成的是晚餐主菜草案，需要自行补齐蔬菜主食。勾选日期后确认加入计划；已安排的晚餐不覆盖，重复点击不重复添加，预览后计划发生变化需重新核对。
- **库存先吃**：需额外同意发送已同步的示例主体库存名称。跳过已归档、零库存、过期和开封后过期记录，匹配目录菜谱。库存存在不等于食品安全，仍需自行检查。
- **一句话记餐**：例如“午餐在小面馆吃牛肉面，实付25元，600大卡，4星。”生成草稿后进入原有记餐编辑页，核对并保存。未说出的金额、大卡、评分不编造；不会从历史问答或库存补值。

## 推荐与费用

程序从现有菜谱目录执行地区、时间、忌口、人数和预算筛选，并去重、减少相同主料连续出现；模型负责解释，不决定菜谱 ID，不直接写入计划或记录。预算按人数估算整道菜，优先菜谱参考价，否则使用现有食材分量与单价估算规则；无法估算的菜谱在启用预算限制时排除。价格不是实时市场报价。

时间为目录单菜备菜与烹饪时间，不代表多菜整餐并行完成时间。忌口按食材名称与常用别名筛选，不能保证过敏安全。条件过严时只返回匹配天数或无匹配，不放宽条件凑数。模型服务失败时可保留明确标注的目录规则草案。

## 联网与安装

沿用 [0.8.0 接入步骤](ai-assistant-v080.md) 的 SSH 与 USB 反向转发。当前没有公网 HTTPS 域名，手机不能脱离转发直接连接。API 密钥只在服务器，安装包不含上游密钥。

- `outputs/kaifan-monster-android-debug.apk`：安卓调试安装包。
- `outputs/shiku-mvp-unsigned.hap`：鸿蒙开发包，需开发者签名。

两端版本为 0.9.0/code18，包名分别为 `com.kaifan.monster` 与 `com.shiku.foodkeeper`。
