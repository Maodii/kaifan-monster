# AI 真实身份校验接入方案（尚未开通）

保留自定义账号、6位含字母数字的密码规则；已有账号不重建。新增手机号绑定验证，短信服务可选阿里云或华为，必须使用审核通过的签名和验证码模板。当前没有服务凭据，不能发真实验证码。

## 实现边界

- 账号表关联单独手机号验证记录：加密号码、用于去重的HMAC索引、服务商、验证时间、状态；日志与接口只返回脱敏号码，不保存明文验证码。
- 请求验证码绑定登录账号与用途，服务端生成随机码，哈希存Redis并设5分钟有效期、单次消费、错误5次冻结；发送间隔60秒，账号/手机号/IP限流、每日总量预算及异常图形验证。返回通用提示避免枚举手机号。
- 验证成功由服务器写入状态，客户端不能提交 phoneVerified=true 作为凭证。生产环境禁止固定测试验证码、控制台手动勾选、开发万能码或短信降级绕过。
- AI start/direct与异步执行均检查服务器验证记录，未验证返回统一 phone_verification_required。所有账号和管理员也须遵守对用户提供生成服务的准入条件，白名单额度不能绕过实名。
- 已有用户在首次AI提问前绑定手机号；账号、离线记餐、库存浏览保留可用。退出、切换账号或解绑立即更新状态，撤销/注销删除关联数据，告知号码用途与保存期限。
- API密钥只在服务器私有配置；另需签名、模板ID、服务地区、发送限额与费用报警。上线前确认所选验证方式满足本次审核要求。
