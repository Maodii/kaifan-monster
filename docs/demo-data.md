在`backend`目录重新写入：

```sh
node --env-file=../.env --import tsx scripts/seed-demo.ts
```

脚本仅允许本地开发数据库，按批次和固定ID避免重复，不覆盖普通账号，也不改变已有演示账号的密码或资料。重复运行到新的一天可生成当天热搜示例。

需要退出演示时，在同一目录执行：

```sh
node --env-file=../.env --import tsx scripts/seed-demo.ts --remove
```

此操作撤回演示动态，移除演示账号的榜单贡献、关注及消息，撤销登录并停用演示账号。保留普通用户及其原有记录；对演示动态发表的真实回复保留在数据库中，随父动态不再公开。批次退役后不会被种子脚本自动重新激活。账号清单和测试凭据文件不会自动删除。

数据保存在当前本机PostgreSQL中，HAP只包含显示演示标记的支持；未连接此API的另一台机器不会自动获得这些社区数据。邮箱验证服务仍需另行配置。
