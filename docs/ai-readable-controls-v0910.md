# 开饭小怪 0.9.10：明确控件与统一回复排版

针对鸿蒙截图中难辨认的 ↓、↺ 和 ↑，将对话控件改为明确文字：浮层“收起”、全页“返回”、“新对话”、回答中“停止”，以及输入栏“发送”。使用紫灰和鼠尾草绿的紧凑胶囊，发送按钮保持固定宽度和居中标签；禁用时也保留可读文字。鸿蒙顶部“最新消息”仅在向上翻看已有问答时显示，空会话不显示该入口。

共享 `AssistantInteraction` 呈现规则用于两端的流式文字、完整回答、历史助手消息和中断内容。处理标题、列表、粗体/斜体/删除线、行内代码、引用、代码围栏、链接/图片语法与常见表格；表格转换为紧凑的“食材 · 用量”行。未闭合的流式粗体/标题/链接标记也作有界清理。保留数量、单位与乘法表达式；用户自己输入的原文不被重写。复制助手回答时输出整理后的纯文本。

所有模型文字仍以普通文本控件呈现，不执行模型 HTML、不加载其图片、不把其链接转换成业务动作。保留正常标题/步骤层次，不引入完整 HTML Markdown 引擎。此实现面向食物建议的阅读排版，不承诺支持全部 Markdown/LaTeX 语法。

修正 Android 顶部“停止”行为：停止推理并保留已收到内容，与原生行为一致；不会把停止误作清空会话。
