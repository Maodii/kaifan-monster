本轮在已有详细模型上加入30个物品的直接选择、上下文操作和有界反馈，没有重新导出或替换原始Blender模型。共用两端相同的离线运行时代码；业务操作继续进入原生页面和原数据库。

轻点锅、柜体或冰箱门，会直接开合实体并显示后续操作；其他已配置物品先就地选中，再选择功能。长按仍可查看细节。新增“物品”目录让体积小、遮挡或远处的物件也能点选，支持键盘；保留简洁版和全部功能入口。

保鲜抽屉将移动的盒体、食材与滑动部分拆到独立运行时运动组，固定导轨及安装螺丝留在机身。开抽屉时打开冰箱门；关门前收回抽屉，防止相互穿插。库存消耗、采购、记餐都需要在原业务页面确认，摸模型不会扣库存或新增记录。

手账显示原快照中的真实三餐摘要；库存和收藏显示当前总数。展示性食材模型不是示例主体库存的逐件数字孪生，点击鸡蛋托进入库存/菜谱搜索，不伪造鸡蛋数量或冒充已按鸡蛋筛选。

渲染增加128×128的共享织纹法线与粗糙度微细节，保留原颜色纹理和UV；每个场景最多两张小纹理，随模型统一释放，无新增全屏后处理。锅盖沿用真实抬升与倾斜、短时蒸汽；物品选择使用克制的抬起/倾斜反馈。减少动态、切后台、切场景和关闭操作均收尾，不留下半截姿势。

当前鸿蒙模拟器仍拒绝WebGL上下文，因此继续显示明确标注的场景预览，不展示可用实时物品操控的假象。直接3D交互已由打包运行时的真实鼠标拾取和桥接路由回归验证，手机GPU、触控与帧率仍待真机验收。
