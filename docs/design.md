# 食库交互与美术

当前界面采用食物手账与杂志排版：象牙白纸张纹理、鼠尾草绿、陶土橙和墨蓝，搭配透明手绘食材、陶器餐桌横幅与细线导航。文字、表单、用量和确认按钮均为原生ArkUI，生成图只作为装饰素材，不把整张概念图当操作面板。

## 字体与层级

正文、标题及输入统一使用 HarmonyOS Sans SC 系统无衬线字体，取消此前运行时文楷标题。通过字号、字重、留白、细分隔线与小号栏目标签建立层级。页面采用低对比纸面纹理、半透明白卡、渐变和轻描边；导航图标使用透明细线SVG，不加实心色块底。

头像提供番茄、米饭、小厨喵、蘑菇四款透明插画；账号页支持相册上传自定义头像。地区、饮食目标和头像优先点选；昵称、简介才使用文字输入。

## 交互

- 录入分为选食材、整理信息两步；模板预填、数量步进、单位、位置及日期快捷值减少输入。
- 价格、备注、批次和标签折叠；保存按钮固定在底部。消耗、丢弃、家庭分享和制作扣库存均显式确认。
- 分量工作台使用餐桌横幅与分组行：人数、食量、咸淡、辣度可独立选择，食材名与推荐数量对齐。重复换算依据折叠；应用推荐只改变制作草稿。
- 一餐多菜支持逐菜编辑花费，金额按分相加；日记支持日历、餐次、地点、评分和示例主体热量。
- 账号支持注册、登录、重启保留会话、资料编辑、版本冲突提示和退出。资料返回前提醒未保存修改；同步过的本地食库仍绑定原账号，避免误上传给其他账号。

`art-source/editorial-paper-header.png`、`editorial-avatars.png` 及同名长提示词为本轮必要原图。实际通过配置的api-image服务生成；第一张返回887×1774，横幅派生后有放大处理，不宣称其为原生1536细节。

正式资源在 `client/entry/src/main/resources/base/media/`：`paper_ivory_tile.png`、`portion_editorial_header.webp`、`avatar_editorial_*.png`、`nav_line_*.svg`。既有食材及菜谱插画继续用于内容卡片。旧原图、字体来源和许可保留在art-source供编辑与溯源，不代表仍作为界面字体加载。

客户端和后端运行时均不包含生图密钥。真实设备截图只放 `work/screenshots/`，资源分类及实际接入路径记录在 `work/artifacts.json`。验证范围见 `docs/acceptance.md`。
