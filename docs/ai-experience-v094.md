本轮覆盖已批准的 24 项方向。01–23 完成代码与宿主/服务端范围验证；24 完成宿主适配矩阵，物理设备验收待设备连接。Android 为原生容器加共享业务与 Web UI，HarmonyOS 为 ArkTS 原生 UI；宿主截图不代表鸿蒙真机截图。

## 可使用的变化

首页只保留“小怪帮你”主入口，点击展开半屏面板。库存、记餐和单菜页面各自展示相关帮手；记餐面板分别通向做饭推荐与外食/外卖编辑，继续共用今日记录和统计。外食地点仍是次级选填。

对话推荐卡使用真实菜谱对应图片、耗时和参考费用；看做法返回保留会话。计划进入确认或编辑，采购先预览缺口，均不自动落库。新增行可撤销，后续编辑或切换账号后拒绝旧撤销，不影响既有记录。

带整餐进入后可选择便宜、快、少辣或换一道，先预览再采用。锁定菜、人数和排除条件保留；换一道只换一份未锁定菜。更快以当前餐单实际估时为基准，外食使用候餐用餐估时和人均预算，均为估算而非餐馆实时数据。没有满足全部条件的结果就保留原餐单。

单菜问答附带本地结构化食材、备菜、烹饪与避坑卡，步骤内容来自当前菜谱，能进入做菜和已有计时器。替换仅提供经规则整理的小范围选项，说明比例、口感、操作与限制；确认形成此次草稿，不覆盖原方，也不把替换后的原费用继续当作已知。普通自由问答仍以连续正文显示，不将模型猜测标成已验证菜谱。

普通问答可展开人数、空余时间、口味选择，允许不指定或直接跳过；进入具体菜品或餐单会清除旧选择，避免隐藏条件冲突。不会推断过敏信息，不会自动授权发送库存。

六枚新生成功能图标已经接入两端；统一纸底、葡萄紫、番茄红、鼠尾草绿和蜂蜜黄，正文保持可读字体，食物图采用完整留白和接触阴影。小怪保留六姿态，以有限图层/固定锚点过渡，后台停止计时；减少动态效果时保留静态状态与操作入口。已有页面转场统一轻量时序，Android 推荐图卡衔接详情、快捷面板管理焦点和返回键；HarmonyOS 使用同图 geometryTransition 及原生路由动画，实际观感仍待设备验收。

## 网络与边界

服务端提供私有短期流式任务：POST 创建，GET 按 UTF-16 游标取真实增量，DELETE 中止上游。不是本地逐字播放。每个任务最多 8,000 字、25 秒运行期限；最多 64 个保留任务，完成后约 60 秒淘汰，进程重启不保留。单进程内相同用户/请求号去重，跨实例不保证去重；当前部署为单实例，不据此承诺 exactly-once 计费。请求号会随问题、条件或授权改变；传输失败重试沿用原号，减少重复推理。

网关实际调用上游 SSE，按 NDJSON 转交后端；总超时、响应大小、并发和费用限制继续生效。取消/断开关闭连接，后台和离开页面取消等待并丢弃晚到回复。对话不写本机数据库或日志；服务端短期内存任务按用户隔离，社区继续隐藏。

公共目录新增版本 ETag，未变返回 304；客户端同一地址复用内存 manifest，切换服务地址不复用旧 ETag。原有按内容哈希只下载变化菜谱、事务安装和旧目录可读能力保留。私有业务数据不进入公共缓存。Android 远程图片限制类型及 8 MiB 传输上限，关闭/读完断开连接；已有本机图片、有限图标尺寸及惰性加载继续使用。

## 安装与未完成的外部验收

正式交付路径保持不变：`outputs/kaifan-monster-android-debug.apk`、`outputs/shiku-mvp-unsigned.hap`。版本 0.9.4 / code 22。Android 调试签名 APK；鸿蒙 HAP 未签名，需要在开发者环境签名后安装。
