# 下一轮 20 项交付验收

本轮为“寻找继续开发的方向和优化方向 → 全部制作”的实施记录。代码、宿主回归、服务部署与原生设备验收分别记录；没有设备证据的项目不视为已验收。Android 的独立状态见 `docs/android/acceptance.md` 和 `work/android-status.json`。

| 项目 | 已落地内容 | 验证与边界 |
|---|---|---|
| 1 双端对齐 | 共用菜谱稳定 ID、核心业务源及版本化 API；Android 独立适配界面与原生桥 | 源码/打包契约可验证；逐页视觉与设备行为尚未完成验收 |
| 2 离线及重启 | SQLite 事务、outbox、独立账号空间、离线计划与本地记录 | 实际 SQLite 回归通过；本轮真机断网/重启未执行 |
| 3 共享契约 | 扩展开封、分摊、试做、剩菜字段，新增独立工作区端点 | 19 套回归；旧六类同步实体及游标兼容 |
| 4 性能基线 | 设备显式选择的基线脚本、限时限内存模拟器守护 | 本次无设备基线；不能据此声称启动速度/FPS 达标 |
| 5 同步中心 | 待传、照片重试、记录冲突、同步消息与最后成功时间 | 编译及核心回归通过；原生页面待验收 |
| 6 跨端工作区 | 计划、收藏夹、偏好、家庭档案版本同步；本地/云端明确选择 | PostgreSQL 并发 CAS、账号隔离、SQLite 原子应用通过；整份选择，非字段级合并 |
| 7 访客迁入 | 访客不自动绑定新账号；备份预览后显式合并 | 账号空间和事务导入回归通过；不自动上传 |
| 8 批量常买 | 一次最多30项，单位/位置模板，数量日期价格确认 | 批量写入与 outbox；非法输入整批拒绝 |
| 9 开封管理 | 原到期日保留、开封日及人工确认到期日，按较早日期使用 | 推荐、筛选、预览和实际扣减均排除开封过期库存 |
| 10 撤销 | 最近5分钟的消耗或采购勾选；反向流水与 outbox | 后续修改、已同步或重复撤销拒绝；采购入库后旧撤销失效 |
| 11 超市采购 | 大触点勾选、已购折叠、包装数×净含量、确认入库 | 已购与入库原子提交；包装换算由用户确认 |
| 12 扣减预览 | 实际批次、用量、余量、费用、缺口预览 | 非变更预览及真实事务扣减回归通过 |
| 13 剩菜安排 | 关联原餐、份数、未来日期；食用后记餐并完成计划 | 不重复采购、扣库存或计费；重开计划也禁止重复记餐。保存安全需自行确认，不自动推断保质期 |
| 14 家庭档案 | 参与成员食量、忌口合并；菜谱可带入人数及平均食量 | 忌口为硬限制，份量预览后显式应用；不代替医学判断 |
| 15 推荐反馈 | 有依据的理由；撤销匹配菜谱/场景/动作的最近反馈 | 本地与服务端匹配动作撤销，避免误删打开行为 |
| 16 替代食材 | 保守替代表、比例与口感说明、用户确认示例主体副本 | 原菜谱不变，硬忌口继续排除；非无限制 AI 替换 |
| 17 菜谱质量 | 完整性分层、缺失主料量、出处与依据按需展开 | 未知量不伪造，完整性标签不代表内容已人工校对 |
| 18 外食记账 | 常用地点、餐费/配送/优惠、示例主体分摊 | 整数分计算；服务端拒绝合计/示例主体份额不一致，旧记录兼容 |
| 19 试做社区 | 成功/需改进、实际耗时、替代材料和失败经验 | 公开保留试做内容，隐藏私人费用与本地文件路径 |

## 验证证据

- `work/reports/next20-tests.json`：19 套回归汇总及逐套日志。
- `work/reports/next20-core.json`：实际 ArkTS 业务在真实 SQLite 适配上的事务检查。
- `work/reports/next20-workspace-api.json`：真实 Nest/认证/PostgreSQL 隔离、并发、校验及隐私检查。
- `work/reports/next20-services.json`：3000/3001 本地服务、目录哈希、社区分页、管理端资源、容器编译产物一致。
- `work/reports/next20-build.log`：原生 ArkTS HAP 编译。
- `work/reports/next20-release.json`：当前单份 HAP、正式资源与454张独立封面核验。
- `work/reports/emulator-memory-guard.json`：模拟器启动约20秒达到3GiB限制，由守护停止；尚未连接 hdc，不代表应用泄漏证据。
- `work/reports/harmony-performance-baseline.json`：无显式设备，未执行性能采样。

## 本地入口

- 首页 → 常买几样 / 同步状态。
- 设置 → 生活工具 → 同步、常买、家庭、撤销、迁入。
- 食材详情 → 开封；采购 → 超市模式 / 采购后入库。
- 菜谱 → 用量与采购 → 带入家庭食量；实际做菜 → 扣减预览。
- 编辑已保存记餐 → 剩菜安排；计划 → 吃过了，记这一餐。
- 记餐 → 费用分摊 / 试做记录；社区可显示公开试做经验。

## 尚需环境完成的验收

本地服务与测试包可交付；最终鸿蒙及 Android 的安装、冷启动、离线重启、拍摄相册、通知、卡片、大字、转场与内存基线均需安全可用的设备环境。本轮不反复启动高内存模拟器，也未打开前台窗口。未配置真实邮件、华为云和公网服务，不把本地服务当作已上线。

## 双端交付核对

Android 0.2.0/versionCode4 已构建；30组宿主UI、14组核心、8组新增事务/契约、9组包核验通过。主对话独立比较两份包哈希、29个共享源模块、Android页面/原生适配源码及当前鸿蒙页面指纹，见 `work/reports/next20-dual-release.json`。Android为独立界面与原生桥适配，共享核心不等同逐像素一致。APK可供安装测试；HAP为unsigned，需设备签名。两端都尚未通过本轮原生设备验收。
