# 鸿蒙云端增强接入计划

用户确认可采用华为云函数与云数据库。当前先交付本地可运行版本；本文件记录接入目标，不代表云服务已开通或迁移完成。

## 数据与职责

- 客户端本地 RDB 保留库存、采购、用餐记录、计划、偏好和离线菜谱。记餐、抽菜与推荐不依赖联网。
- 云函数处理需要可信服务端执行的鉴权、同步、家庭成员权限、社区发布与审核。推荐核心可复用纯逻辑模块，离线推荐仍在客户端执行。
- 云数据库保存账号资料、同步实体、家庭关系、社区内容及操作版本。照片文件使用配套对象存储，数据库仅保存对象标识和关联信息。
- 价格与热量估算继续明确标注为推荐估算。

## 接入边界

1. 先核对目标 HarmonyOS SDK 可用的华为云开发产品、区域、云函数运行时及数据库能力，再确定官方 SDK 与部署配置；不预填未经确认的 SDK 包名或控制台资源 ID。
2. 保留客户端现有业务数据接口，通过远端适配层切换本地 NestJS 服务与华为云服务。当前 NestJS/PostgreSQL 实现继续用于本地测试。
3. 首批接入示例主体资料与私有同步，再迁移家庭协作与社区。现有密码摘要、登录令牌不能假定可直接导入华为账号体系，需明确登录映射和重新认证流程。
4. 保留实体 ID、版本、更新时间、删除标记和幂等操作 ID。以现有冲突合并及权限行为为验收基线；数据库不支持跨实体事务时，必须先验证替代的一致性方案。
5. 私有数据按账号隔离，家庭数据按成员权限访问。同步、家庭撤权、审核状态变更通过受控服务端入口执行；不能让客户端任意写入可信权限字段。
6. 上传使用受限授权，公共照片须经过发布及审核；私有用餐照片不自动公开。云服务密钥不放入客户端资源或源码。

## 开通前验收清单

待用户准备华为开发者项目、服务区域与所需产品后，执行独立测试环境部署，并验证：离线新增后同步、重试幂等、双端冲突、删除同步、跨账号隔离、家庭撤权、私有照片隔离、社区审核及失败恢复。通过后再决定是否迁移已有测试数据。

本轮没有创建云资源、上传用户数据、引入云 SDK 或替换现有后端。
