# 0.9.17 双端交互修整

顶部避让系统状态栏、摄像头及底部手势区域；安卓 API30+ 由原生容器统一应用窗口 Insets，旧系统采用系统窗口适配，防止重复计算安全区。键盘展开时优先关闭键盘。

登录页仅保留账号、密码和登录，右下角引导注册。首次登录自动把尚未归属其他账号的访客记录带入当前账号空间，保留照片引用。重复登录不覆盖账号修改，其他账号不能再次认领。已有云端归属的旧数据不自动转给新账号。这里只完成数据归属；云端同步仍按既有开关执行。

抽餐默认一道菜，条件折叠，使用过的自定义方案在下次保留。展开条件时压缩形象占位；主形象可打开 AI，不再叠加悬浮小怪。揭晓动画可取消，取消不修改结果，减少动态效果设置可跳过动画。

AI 回答时发送键切换为暂停，新对话按钮暂时禁用。主页面系统返回退出前台，子页面仍正常返回，未保存编辑继续提示。

已验证：504 组宿主响应式布局、56 组 AI UI、8 组输入与返回交互、6 组本轮交互、4 组访客归属、7 组 AI 核心和13 组离线 SQLite 核心；双端编译、安卓签名和资源一致性、鸿蒙发布签名通过。鸿蒙模拟器覆盖安装和只读页面走查通过，非首页主标签系统返回可离开应用。未触碰用户账号和业务记录。

限制：安卓真机异形屏、厂商键盘与系统返回仍需复测；本轮本地 API 未启动，未重跑真实 HTTP 集成组。鸿蒙发布 HAP 是模块包，不等于应用商店提交用的完整 APP 归档。

验收记录：work/reports/ux-v0917-acceptance.json。测试安装优先使用相同签名的覆盖安装，不卸载旧版，以免丢失未同步记录。
