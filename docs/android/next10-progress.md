# Android 0.3.0（versionCode 5）

当前交付为独立Android界面与原生平台适配，31个业务模块来自稳定的ArkTS共享源。已接线convenience.js，不再保留为未加载草稿。

- 首页四餐快捷记餐、最近实际用餐复用均先编辑后保存；所选历史日期保留，未来日期进入计划。三餐显示已安排菜品，支持直接调整计划；顶部搜索、快捷入口顺序及插画按当前Index核对。
- 采购支持实际数量/单位、现有库存及历史购入参考。部分购入原子入库并保留余量；全部买齐也校验数量与打开页完整快照，同毫秒修改、超买、不同食材/单位/家庭范围均拒绝。
- 库存历史按批次搜索、消耗/丢弃/在库筛选和分页，撤销流水标注为撤销恢复。
- 参考热量、四类来源与实际食用比例；保存实际摄入，编辑重存不重复乘比例，未知仍为未知。
- 今天跳过仅影响同场景推荐、每日一菜和抽餐，至本地午夜；主动菜谱库、搜索和收藏仍可查看。长期不抽单独设置，临时跳过不发送学习事件。
- 逐条合并计划、收藏夹、筛选、成员与偏好，冲突须选择；共享摘要显示日期/菜名/人数/收藏内容/成员忌口；提交仍检查本地签名与云端CAS。
- 整餐逐道/双灶参考和荤素搭配，延续共享时间、预算与忌口约束。
- 菜谱内容问题进入已部署纠错队列，不改写原菜谱；登录、类别与2至1000字边界保留。
- 同页焦点和折叠状态保留，忙碌及选择状态可访问；筛选11组无前置勾，餐次4张正式插画恢复，底部操作固定。
- 菜谱库改为24条显式分页；卡片、主页面搜索、纸张纹理尺寸、首页餐食卡片和底栏参照当前正式源码调整。
- 统计按餐次与标签使用示例主体分摊金额，新增菜品构成/食材消耗与浪费；CSV导出当前时段，包含示例主体花费、实际热量、来源、整份热量和食用比例，保留表格公式转义。
- 页面版本从Manifest构建元数据生成，原生设备信息从PackageManager读取，避免独立写死的版本显示。

实际证据以work/reports/android-release.json及其绑定的core/UI/next20/next10报告为准。正式媒体逐文件比较；截图由Playwright生成，不是Android设备截图。无连接Android设备，未启动模拟器，安装后原生视觉、字体缩放、相机/通知/小组件及性能仍待真机验收；没有宣称逐像素相同或完整设备验收。
