## 0.1.1 资源与视觉纠正

旧版不是资源被删除：Android 用 ID 推算菜图名，与共享 RecipeCoverMap 的 64 个 dish_v3 映射不一致，导致文件虽入包但 UI 请求 404。构建现在直接提取共享映射；454 个 UI 实际地址全部通过浏览器解码，私有未知 ID 与鸿蒙一致回退菜谱图标。发布校验同时检查映射、调用方及包内字节。
