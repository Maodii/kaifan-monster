# Android 下一轮20项接入记录

对应共享范围：`docs/next20-scope.md`。本轮0.2.0/versionCode4，单份APK覆盖交付；仍不宣称与鸿蒙逐页完全一致。

| 方向 | Android 实际接入 | 验证与边界 |
|---|---|---|
| 1 双端对齐 | 同一正式图标/454张映射/字体，11组无勾居中筛选，月历/设置/成品/记餐/抽餐子页 | 包内逐字节核验；逐页视觉一致性仍未验收 |
| 2 设备闭环 | 既有adb安装/WebView/重启持久化脚本保留 | 无设备；未启动模拟器，未执行真机断网闭环 |
| 3 契约一致 | 直接转译最新29个共享模块，保留源哈希；新事务与工作区真实HTTP契约回归 | 宿主SQLite及实际本地API通过；不冒充双设备对照 |
| 4 性能基线 | 新measure-device.py：指定设备后5次冷进程启动/应用PSS采集 | 当前not_executed_no_device；不编造首屏可用/帧率或内存达标数值 |
| 5 同步状态 | 唯一待传记录/修改次数/待传照片/冲突/家庭阻断/lastSync；单张照片上传入口 | 成功时间只取核心成功记录；家庭状态未核对前明确待核对 |
| 6 计划偏好同步 | 本机/云端明细，显式整份上传/下载，CAS及稳定workspaceSignature；旧Android偏好一次迁入规范键 | 真实API JSONB读回/过时版本拒绝通过；UI不自动覆盖 |
| 7 访客迁入 | 登录后选JSON备份、范围/重合预览、保留现有ID、原子导入 | 家庭记录拒绝迁入；照片标识剥离，不自动上传；宿主UI验证 |
| 8 批量常买 | 从实际历史取最近单位/位置，逐行确认数量/日期/金额，独立批次整批原子入库 | 增加候选保留已改字段，失败回滚通过；默认日期须用户确认 |
| 9 开封批次 | 开封日/人工确认开封后到期日，原到期日保留；核心按较早日期处理 | 宿主保存与扣减预览验证；不杜撰食安保存期限 |
| 10 可撤销 | 最近消耗和只标记采购撤销；调用共享5分钟/当前快照约束 | 后续修改拒绝；真实采购入库取消旧标记撤销；宿主SQLite验证 |
| 11 超市模式 | 固定分类、大触点、已买默认折叠、包装数与总量分别记录 | 沿用确认实际数量后入库；只标记不改库存；切模式不写数据 |
| 12 扣减预览 | 共享previewDeduction逐批显示用量/剩余/分摊，确认前重算并阻止过时预览 | 原子cook重新校验，未知量/不足停止；预览不写库存 |
| 13 剩菜备餐 | 记餐剩余份数，关联sourceMealId/remainingPortions进入计划 | 计划不重复采购/费用；食用时通过recordLeftoverPlan生成0费用记餐，原子完成且防重复，宿主UI/SQLite通过；不承诺自动安全期限 |
| 14 家庭偏好 | 启用/停用成员、参考食量、忌口并集，推荐/筛选/抽餐均合并硬限制 | 家庭云端成员关系与本机用餐档案分开；实际筛选约束验证；家庭人数/食量按钮只更新预览，应用推荐另需明确操作 |
| 15 推荐反馈 | 按核心事实展示最多2条理由；匹配菜谱/场景/action撤销，在线记录成功才删除对应云反馈 | 本机撤销事务与接口契约接入；跨设备并行反馈需进一步设备联调 |
| 16 缺料替代 | 共享替代选项/口感说明，显式确认后保存私有副本 | 原菜谱不改；合并忌口过滤，核心回归通过 |
| 17 菜谱质量 | 共享recipeQuality，未知主料/时间估算/来源缺失按需显示 | 无依据时不标已核实；宿主详情渲染通过 |
| 18 外食费用 | 常去地点建议，餐费/配送/优惠/份数，mealTotal/personalCost独立于items合计 | 整数分分摊11元/3份=3.66元，统计复用personalCost；宿主回读通过 |
| 19 社区经验 | 成功/失败、实际分钟、替代材料、失败心得随记餐保存，发布前预览 | 共用后端公开白名单；费用分项默认私有；主对话HTTP白名单报告通过 |
| 20 视觉/无障碍 | 无勾筛选、aria-pressed/current、具名头像/添加入口、焦点、大字相对字号、系统减少动画 | 200%字号关键页无横向溢出；TalkBack及逐页视觉仍待设备验收 |
