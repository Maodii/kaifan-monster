# 开饭小怪本地原生测试版（2026-11-05）

安装包：[shiku-mvp-unsigned.hap](../outputs/shiku-mvp-unsigned.hap)。当前文件大小、SHA256、原生测试与包内资源核验见[发布报告](../work/reports/gesture-motion-release.json)。沿用包ID `com.shiku.foodkeeper`，覆盖安装保留原本机数据；显示名称与图标改为用户选择的④开饭小怪。

## 手势与转场更新

主页面左右滑动按底栏顺序切换，日历支持切周/切月，烹饪页左右翻步骤，应用左侧滑动返回。切页保留浏览位置；点当前底栏或双击菜名回顶。新增方向转场、跟手及取消回弹、按压反馈、列表与日历过渡，均兼容减少动画。原生三组专项通过；未保存记餐返回仍需确认，测试草稿已放弃、减少动画设置已恢复。屏幕最外沿保留HarmonyOS系统操作。详见[手势与动画说明](gesture-motion.md)。

## 排版精简更新

筛选蜡笔底纹在组件内居中，记餐标题单行显示。菜谱及烹饪页顶部固定菜名、返回及爱心按钮；收藏和取消有轻弹/回缩动画并支持减少动画偏好。删除重复的正文菜名、收藏文字、“只记我吃了这道菜”按钮，将工具收进准备栏，成品入口精简；不再抽到、私有菜谱编辑与公共审核收纳到“更多”。

[实际原生专项](../work/reports/native-compact-layout.json)验证固定栏、收藏往返及初态恢复、记餐标题单行与筛选布局。本轮没有新增用餐或扣减库存；未进行帧率基准或全套搜索重测。

## 启动与图标更新

桌面图标去除实色底，小怪主体宽度占比约86%；启动页使用独立透明小怪，约93%画布占比。首页Logo框从58增大到72。默认转圈替换为小怪轻呼吸和三色活动点，本地数据就绪后260ms淡入首页，不添加最低等待时间；减少动画偏好关闭活动动效。真实后台模拟器冷启动与重复启动通过，截图覆盖桌面图标、过渡帧及首页；未做帧率或启动耗时基准，未注入存储故障。

## 本轮入口

本轮菜谱浏览、抽餐独立筛选、返回位置与离线容错搜索详见 [交互说明](discovery-interaction-iteration.md)。新增拼音、错字、中文拆词及明确不辣/排除原料/时限搜索；后端HTTP目录搜索仍沿用既有实现。华为云函数与云数据库接入记录在 [云端计划](harmony-cloud-plan.md)，目前服务仍在本机。

- 今日：默认今天三餐；点周历查看其他日期，点“月历”展开月份。历史显示实际记餐与计划，未来通过“安排”建立计划；“回今天”返回今日。80条原创食物标语按日稳定轮换。
- 菜谱：454道菜各有独立透明手绘封面；支持综合排序、价格升降序、耗时升降序；菜谱大全连续滚动，同菜不同做法可在详情切换。卡片标出两人份预计费用，详情按基础人数展示；估算分菜谱参考、食材估算、同类估算，不冒充实时报价。
- 菜谱详情：点“食材”或“调味料”，再点具体名称展开参考量、准备状态和品类替换。做法、可保存步骤与倒计时保留。
- 今日“每日一菜”或菜谱“抽一餐”：选择菜汤组合、人数、可用时间与预算，抽完查看逐菜做法或合并备料；结果支持重抽。严格预算筛选仍拒绝把未知成本当作零。
- 我的 → 口味与抽菜：做饭偏好、外食/外卖偏好、不喜欢的菜三个分类入口。筛选项取消前置勾，文字居中，选中通过蜡笔纹理与字重区分。
- 我的 → 账号与同步 → 登录/注册：邮箱、密码、注册昵称与确认密码；错误持续显示，连接设置按需展开。账号资料按账号缓存，退出恢复本机档案；新绑定默认关闭自动同步。

## 安装与运行

已在本任务后台模拟器覆盖安装。重新安装：

```sh
source scripts/harmony-env.sh
hdc install -r outputs/shiku-mvp-unsigned.hap
hdc rport tcp:3000 tcp:3000
hdc rport tcp:9000 tcp:9000
hdc shell aa start -a EntryAbility -b com.shiku.foodkeeper
```

包为未签名模拟器测试HAP；真机需在DevEco Studio打开client并配置自己的签名。本地服务地址 `http://127.0.0.1:3000`；核心本机功能可离线使用。照片对象服务使用9000端口。

容器API可通过下列命令启动，端口为3001，与当前原生应用使用的3000本机API区分：

```sh
API_PORT=3001 docker compose -f compose.yaml -f compose.app.yaml up -d
```

健康接口为 `/api/v1/health`。本轮未部署外部服务器。
