# 华为审核反馈整改 · 2026-11-17

截图是本次审核反馈的依据。官方文档链接已访问，但当前公开网页仅返回前端壳，未取得完整条款正文，因此不宣称完成法律适用判断。

|反馈|性质|处理与剩余事项|
|---|---|---|
|APP核准/备案未通过|上架阻断|在华为开发者中心「开发者管理→所有应用→开饭小怪→分发→版本信息→备案信息」填写已获批的APP备案信息。主体、名称、包名与获批材料一致；大陆服务器不能选择“服务器不在境内”规避。备案从接入服务商阿里云备案控制台办理，域名/网站备案不自动等于APP备案。|
|缺少AI文本生成资质|上架阻断|按反馈补充安全评估报告、全国互联网安全服务管理平台提交及通过结果截图。百炼模型资料可辅助，不能擅自认定替代应用报告。|
|缺少AI生成合成标识材料|上架阻断|应用已有显式提示，仍需提交真实生成结果标识截图及平台要求的其他标识材料；旧入口宣传图不足。|
|AI生成前未实名|上架阻断|自定义账号密码可保留，但AI前需手机号等真实身份验证。尚无短信服务、已审核签名/模板及验证凭据，不伪造接入。待服务就绪后增加验证码绑定、限流/防刷、服务端准入校验及隐私说明；旧账号也须验证，客户端绕过不可调用。不得收集明文身份证来凑流程。|
|隐私声明托管|非阻断建议|可使用华为标准托管服务提升维护效率，仍需填写真实运营主体与有效联系渠道。|
|计划勾选/取消不及时刷新|体验问题|原计划列表按不变ID复用普通对象构建内容；改为状态/修改版本参与键值，首页计划也同步更新。需在审核同类真机复测。|
|主题/提醒设置异常|体验问题|切换主题曾触发全量提醒重建，提醒页重复登记且全局错误混淆保存结果。增加配置签名、串行登记和失败重试，主题状态刷新；保存结果与提醒失败分离，检查通知权限及提示关闭时的时间保存语义。|
|上传图标透明|提审资源问题|替换商店1024PNG为满幅RGB纯色底，保留小怪；应用内部透明角色/分层前景保持用途不变。|

## 需要开发者办理的材料

APP备案成功信息；AI安全评估通过材料；短信服务与审核通过的签名/模板；真实运营主体及客服/隐私联系渠道。API密钥通过服务器私有配置提供，不应粘贴到公开说明或打包进客户端。

当前实际包含AI功能，不能在备注里填写“没有AI相关模块”。如果选择暂时不提供AI，需要双方客户端和服务端真正关闭生成能力、同步商店描述后另行验证，不能只隐藏图标应付审核。本次没有自动关闭现有AI服务，也没有代提交审核。
