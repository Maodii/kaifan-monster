# 0.4.1 搜索与地点显示调整

- 顶部搜索入口仅在菜谱与社区出现，首页及其余主页面不显示全局搜索。
- 入口和搜索输入行居中、最大480；Android宽88%，鸿蒙宽78%以补偿ArkUI父容器内边距的百分比计算（1280px模拟器实测998px）；长关键词单行省略。
- 菜谱搜索使用菜谱输入、历史、菜谱热度与菜谱结果；社区搜索独立输入、帖子结果、分页游标与返回路径，不改变原广场列表，不写入菜谱历史或热度。
- 社区搜索在服务端按可访问帖子标题、正文、话题及试做经验查找，组合原分区/筛选；最多80字符，百分号与下划线按字面匹配。不同关键词不可复用游标；不检索私有地点和价格。
- 社区搜索在账号切换或退出后清空；迟到响应检查请求序号、账号和页面；换原分区/筛选后不沿用旧结果。
- 首页最近吃过仅显示“再吃一次”，不显示地点或用餐方式，旧记录不再出现undefined/null。
- 地点只在餐馆、食堂、外卖与兼容外食记录的折叠详情中选填；在家隐藏；保留已有历史值，其他外食统计仍可用。

证据：work/reports/search-polish-tests.json（24套回归）、search-polish-api.json（7组服务端集成）、search-polish-ui-source.json（路由与入口检查），以及最终search-polish-release.json/search-polish-dual-release.json。Android宿主真实点击、两种宽度布局和缺字段记录由android-ui-tests.json验证；宿主截图不等于设备截图。真机相机、通知和双端像素一致性不在本次验收结论内。

鸿蒙现有模拟器已完成6项定向检查：入口收窄居中、菜谱搜索页、首页无搜索、独立社区搜索页、在家展开详情无地点、外食展开详情有地点；未保存测试记餐。证据为 `work/reports/search-polish-native.json` 和登记截图。未启动新模拟器。
