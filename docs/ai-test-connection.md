# 鸿蒙模拟器连接 AI 测试服务

云端 API 经本机 SSH 转发位于 `http://127.0.0.1:13000`。应用在模拟器内访问的 `127.0.0.1` 属于模拟器，因此还必须建立 HDC 反向转发；仅有电脑的 SSH 隧道并不足够。

1. 在 DevEco 中启动已有模拟器，保持运行。
2. 在项目根目录执行 `python3 scripts/connect-ai-test.py --platform harmony`。它会先检查服务，再选择唯一连接目标并建立 13000/19000 转发，鸿蒙额外将旧版设备端口 3000 映射到电脑 13000；不会启动或重启模拟器，不会更改账号。多个设备时用 `--target` 明确指定。
3. 应用账号页展开“服务连接”，地址填写 `http://127.0.0.1:13000`，点“检测连接”。应显示“已连接”。
4. 注册或登录自己的账号，点击小怪打开对话，勾选本次发送同意后提问。

0.9.8 及之前的鸿蒙“使用本机测试服务”按钮填入的是 3000，面向旧本地服务，并非当前云端隧道端口；连接脚本现已兼容这个旧端口，也可直接手动填写 13000，无需为测试重装应用。0.9.9 已将此按钮明确为“连接云端测试服务”，使用 13000；检测成功保存地址。真正的本机开发服务仍可手动填写原地址。

断开模拟器、关闭电脑 SSH 隧道或重启调试服务后可能需要重跑连接命令。暂无公网 HTTPS 域名时，这个测试连接不能脱离电脑使用。不要把服务器明文 HTTP 地址或模型 API 密钥填进客户端。

当前服务器真实模型调用结果：`work/reports/assistant-cloud.json`；设备连接状态：`work/reports/ai-device-connection.json`。服务器端验证不能替代设备端点击与软键盘验收。
