# 社区图文演示

本轮新增8篇带照片的虚构帖子，使用现有演示账号发布。当前演示社区合计32篇动态，其中8篇为本轮AI照片图文帖；照片合计约2.1MB，每篇单独对应一张图。

| 帖子 | 配图 |
| --- | --- |
| 晚饭不用复杂，一盘番茄炒蛋就够香 | 番茄炒蛋与白米饭 |
| 明天的便当，今晚先安排好 | 鸡胸肉、西兰花与糙米便当 |
| 降温之后，想喝一碗热乎的汤 | 冬瓜排骨汤 |
| 豆腐也能当晚饭主角 | 香菇老豆腐 |
| 不想做饭的晚上，认真吃一碗面 | 虚构面馆的牛肉面，无真实商家信息 |
| 把早餐吃暖一点，今天慢慢来 | 南瓜小米粥与熟鸡蛋 |
| 周末两人餐，清蒸鱼也有仪式感 | 清蒸鱼与双人餐桌 |
| 外卖也可以搭配得清爽一点 | 无品牌鸡肉饭与独立酱汁 |

账号昵称为“演示·…”，正文标注“虚构演示 · AI生成配图”，图片内也有“AI生成 · 演示”。花费、评分、餐食故事均为虚构，不声称真实体验。未录入精确热量，未冒充真人或真实商家。

刷新客户端餐桌广场即可从本地API读取；无需重装HAP。带有精确关联菜谱的两篇同时进入对应菜谱成品展示，未匹配的生活餐食不强行关联不相干菜谱。

图片存于私有MinIO对象桶，数据库只保留照片索引和引用。登录用户通过现有照片权限接口获取限时链接；匿名接口与未签名对象下载均拒绝。本轮已确认8张图片真实下载字节与正式JPEG一致，并在无头浏览器内全部解码。原生客户端本次未重新走查，不声称原生端最终视觉验收。

管理端“内容审核→公开动态→已通过”可直接查看照片。演示批次停用功能同时覆盖这些新帖。重复执行`backend/scripts/seed-community-photos.ts`不会重复创建帖子或照片，也不会自动重新发布已撤回的帖子。

本轮已清理被正式压缩标注版替代的8张生图候选，保留正式照片、预览与详细提示词；未创建整项目备份。
