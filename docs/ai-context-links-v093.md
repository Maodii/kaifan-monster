# AI 对话与选菜入口联动 · 0.9.3 / 21

双端在菜谱详情、每日选菜、整餐抽选结果提供进入小怪对话的入口；首页提供一周灵感、库存先吃、一句话记餐三个快捷入口。Android 推荐卡也提供“问小怪”。

进入时展示选中的菜名和可点开的菜谱链接。单菜可问做法要点、换食材；整餐可问备菜与制作顺序，同时携带这次抽选人数。入口仅填好问题，仍由用户确认发送，不会自动生成采购、扣库存或记餐。

选菜上下文最多三道，包含菜名、原方人数、时间、前六项食材名；单菜可携带前两步做法摘录。上下文和问题合计最多 600 字符，不携带照片、账号资料、位置或库存。请求沿用现有 AI 协议，无需服务器升级。

上下文条可关闭；关闭时停止附带上一轮问答，避免沿用刚刚移除的选菜内容。库存先吃仍需单独勾选发送库存。切换场景不会自动开启库存权限。

查看对话里的菜谱后返回，会保留回答和当前上下文。离开时尚未完成的回复不会在返回后突然覆盖当前对话。聊天仅在本次运行内存中保留，数量有上限；新对话、账号变化会清空。
