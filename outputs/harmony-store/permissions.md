# 权限与第三方服务

网络与提醒
联网用于账号、同步、目录更新和你主动请求的 AI；网络状态用于判断 Wi-Fi 同步条件。通知与系统提醒用于你开启的临期提醒和烹饪计时。

拍照、选图与文件
Scan Kit 用于扫码；Camera Picker 用于主动拍照；Photo Picker 仅读取所选照片。文件选择器用于导入和导出；剪贴板仅在你点击复制时写入。拒绝这些能力不影响手动记录。

云端受托服务
阿里云提供云端数据托管；阿里云百炼 API 根据本次授权处理问题及所选上下文，生成饮食建议。服务商隐私政策：https://terms.alicdn.com/legal-agreement/terms/suit_bu1_ali_cloud/suit_bu1_ali_cloud201902141733_81641.html

第三方能力
系统提供数据库、照片选择、文件及提醒等能力。应用未接入广告或第三方统计 SDK。
