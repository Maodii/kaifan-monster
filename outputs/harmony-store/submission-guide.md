## 哪些服务勾选 / 开通

“商店功能声明”与“开发服务API开关”是两件事。AI功能声明必须按实际选择，不能因为没有华为AI SDK就选不涉及。云端AI也不需要把华为AI服务全部打开。

| 项目 | 当前建议 | 原因 / 限制 |
| --- | --- | --- |
| 商店AI生成合成服务 | **涉及**；文本生成/智能对话 | 通过自有后端调用阿里云生成文本；申报AI标识及资质 |
| 应用内购买、订阅 | 不涉及 / 不开通 | 当前无付费商品和支付SDK |
| 广告及广告标识 | 不涉及 / 不开通 | 当前无广告SDK与广告追踪 |
| 华为账号 Account Kit | 不勾选 / 不开通 | 当前为自建账号体系，不是华为账号一键登录 |
| 云数据库、云存储、云函数、云认证 | 当前不因上架额外开通 | 当前业务用自有ECS、PostgreSQL、私有对象存储与自建鉴权 |
| Push Kit / 远程推送 | 当前不开通 | 本地系统代理提醒不等于远程推送；未来加入再接入与申报 |
| Scan Kit 扫码 | 按实际已接入能力检查后台是否要求启用 | 应用调用系统Scan Kit，不是可随意取消声明的“没有扫码”；若后台对该服务要求启用/凭证，按官方接入指南与真机结果办理 |
| 系统代理提醒 / 通知 | 按实际功能声明 | 食材临期和计时由系统提醒能力实现；需实际验证用户授权、设置关闭和送达，不等同Push Kit |

| 相机/系统照片选择 | 如实声明使用场景 | 主动拍照/选图；不申请整库相册、定位、通讯录等无关权限 |

| 内容分级 | 按真实问卷作答 | 饮食生活应用，不含开放社区或游戏；仍有生成式AI，不能保证所有输出天然适合儿童 |
| 支持设备 | 手机优先 | tablet虽在包中声明，但没有完成对应真实验收与商店素材 |

后台服务名称、是否按证书指纹开通、示例主体开发者能否申请及所需资质会变化，以当前控制台为准。需要填SHA256指纹时用本应用发布证书的指纹（见下文），不要误用根证书、调试证书、HAP文件哈希或App ID。

## 当前权限与隐私标签填写依据

实际 `module.json5` 权限只有：`ohos.permission.INTERNET`、`GET_NETWORK_INFO`、`PUBLISH_AGENT_REMINDER`。无定位、通讯录、麦克风、广告追踪权限。系统Picker按需提供图片/拍照；不能因此在后台填“完全不处理照片”。

| 数据类别（以后台名称对应） | 是否涉及 | 用途与触发 |
| --- | --- | --- |
| 账号/用户ID、可选邮箱、昵称与头像 | 涉及、与账号关联 | 主动注册、登录、修改资料；自建鉴权 |
| 设备/登录标识、令牌 | 涉及、与账号关联 | 登录状态、设备管理、安全；不是广告ID |
| 用户内容：食材、用餐、采购、计划、偏好 | 涉及 | 主动同步、家庭功能；本机数据不等于已上传 |
| 照片/图片 | 涉及、可选 | 主动选图、头像或照片同步；私有对象存储 |
| AI问题和回答/所选上下文 | 涉及、按次授权 | 阿里云云端推理，库存与上轮对话另行选择；本应用不持久化私人问答不等于服务商不处理/不留存 |
| IP与必要网络运行/安全信息 | 涉及 | 请求连接、基础设施运行及安全；需核实真实日志保留策略 |
| 地区/饮食目标 | 可选资料 | 用户主动选择，非GPS精确定位；饮食目标不宣称医疗诊疗 |
| 购买历史、支付/金融信息、广告追踪、通讯录、GPS、麦克风 | 当前不涉及对应采集 | 用户自行输入的用餐花费是用户内容，不是交易支付信息 |

不得选择“应用不收集任何数据”。第三方服务按实际阿里云托管/模型服务与系统Kit填写；服务端PostgreSQL/Redis/MinIO不是客户端广告SDK。是否属于“共享”或“受托处理”根据合同、法定义务与后台定义填写，不凭本地没有SDK就隐藏云端处理。
