# AI 功能审核补充说明（待主体确认与补齐证明）

应用：开饭小怪。当前技术验证版：0.9.25 / 43；具体提审版本以控制台上传包为准。运营主体、备案主体和真实联系方式须由开发者确认，本文不代填示例主体信息。

## 实际服务

应用通过自有后端与私有网关调用阿里云百炼 API（当前 qwen3.8-flash），提供饮食领域文本问答、新菜做法、营养与花费估算。按需使用百炼 Responses 的 web_search 检索公开资料。联网结果只展示搜索工具返回的来源，估算不是实测或实付。

用户登录、同意云功能并授权本次发送后才调用云端。库存名称与上一轮问答分别选择发送。应用结果页显示“AI生成 · 仅供参考”，复制功能附加生成提示。菜谱/记餐先进入可编辑草稿，用户保存才写入。

## 本次审核明确要求，尚未具备

1. 安全评估报告，以及全国互联网安全服务管理平台提交结果截图，现场检查“通过”或审核“审核通过”。请按审核通知办理；供应商的模型备案/证明不能自动替代本应用被要求提交的材料。
2. 真实身份校验：当前自定义账号密码不构成真实身份校验，邮箱验证也不能代替。需接入真实手机号验证码等合规验证流程，并在服务端校验状态后开放生成能力；不能只在客户端加勾选或填写假身份证。
3. AI生成合成内容标识材料：补拍当前正式构建的真实生成结果、复制/导出提示和功能说明。现有入口宣传图不能冒充生成结果证据。
4. 按平台要求继续核对隐式标识、导出文件及生成内容传播提示。已有“AI生成”字样不等于全部材料已获认可。

禁止把本说明、测试结果或百炼 API 可用作为安全评估通过证明。材料未齐前不要声明“已全部合规”。也不能以备注“无AI功能”处理当前实际提供AI服务的版本。
